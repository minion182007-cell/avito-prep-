# ping

Минимальный HTTP-сервис на Go: отвечает статусом в формате JSON.
Учебный проект — каркас, на котором разбираются основы `net/http`.

## Запуск

Из корня репозитория:

```bash
go run ./projects/ping
```

Сервис слушает порт 8080. Другой порт задаётся переменной окружения:

```bash
PORT=9000 go run ./projects/ping
```

При старте пишет в лог адрес, на котором слушает.

## API

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/ping` | `200`, тело `{"status":"ok"}` |
| Любой другой | `/ping` | `405`, заголовок `Allow: GET, HEAD` |
| Любой | прочие пути | `404` |

## Тесты

```bash
go test ./projects/ping -v
```

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | Порт, на котором слушает сервис |
